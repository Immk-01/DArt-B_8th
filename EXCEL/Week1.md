## 01-3. 엑셀의 기본 동작 원리 이해하기
> **셀 참조 방식에 대해 정리해주세요.**
[$ 기호 사용에 따라 참조 방식 구분]
1. 상대참조
  '=A1', '=C6 + D6'과 같이 다른 셀을 참조할 때 셀 주소 앞에 '$' 기호가 전혀 포함되지 않는 형식
  작성한 수식을 복사하거나 자동 채우기를 실행하면 참조한 셀 주소도 함께 변경된다.
2. 절대 참조
  '=$A$1'과 같이 열과 행 모두에 '$' 기호를 붙인 형태
  수식을 복사하거나 자동 채우기를 실행해도 참조한 셀 주소는 항상 고정된다.
3. 혼함 참조
  행과 열 중 하나만 고정하는 방식
  "=$C4"의 경우 행만 고정하는 것이고, '=C$4'의 경우는 열만 고정하는 것이다.

## 01-5. 실무자면 꼭 알아야 할, 필수 단축키 모음
> **이번에 배운 단축키에 대해 정리해주세요.**
[Ctrl 조합] : 'Ctrl'과 동시에 다른 키를 눌러서 빠르게 실행할 수 있으나, 제한적인 기능에서만 사용할 수 있다.
1. Ctrl + S : 파일 저장
  +) F12를 누르면 '다른 이름으로 저장' 대화상자가 열려 기존 파일을 유지한 채 새로운 파일로 빠르게 저장할 수 있다.  

2. Ctrl + N : 새로운 통합 문서
  +) Ctrl + Tab을 통해 통합 문서 간 빠르게 이동할 수 있다. 비슷하게 Alt + Tab을 통해 실행중인 모든 프로그램 목록을 확인하고 이동할 수 있다. 
   
3. Ctrl + PageUp/PageDown : 시트 이동

4. Ctrl + 마우스 휠 : 화면 배율 조절

5. Ctrl + F1 : 리본 메뉴 숨기기

6. Ctrl + \ : 기준 행/열의 값과 다른 값 선택 : 선택한 범위의 특정 행이나 열을 기준으로 다른 값을 구분하는 경우 좌우를 비교할 수 있다.)

7. Ctrl + [, Ctrl + ] : 수식에 사용된 셀/사용한 셀 한방에 선택 (현제 셀의 수식에 참조되는 셀과 현제 셀을 참조하는 셀을 추적할 수 있다.)

9. Ctrl + A : 연속된 범위 선택

10. Ctrl + H : 바꾸기 기능 (특정 단어를 다른 값으로 한 번에 변환할 수 있다.)

11. Ctrl + +, Ctrl + - : 새로운 행, 열, 셀 추가 (Ctrl + + : '삽입', Ctrl + - : '삭제')

12. Ctrl + D, Ctrl + R : 선택된 범위의 첫 번째 셀 값으로 자동 채우기 (Ctrl + D 를 누르면 아래 방향으로 자동 채우기가 실행되고, Ctrl + R 를 누르면 오른쪽 방향으로 자동 채우기가 실행된다.)
  +) 단축키를 이용한 자동 채우기는 범위의 패턴은 인식하지 못하고, 첫 번째 셀 값 또는 수식으로만 채워진다.

13. Ctrl + E : 빠른 채우기

14. Ctrl + 1 : 셀 서식 대화상자 열기 

15. Ctrl + 방향키 : 범위의 마지막 셀로 이동 (해당 방향으로 연속된 데이터의 마지막 셀로 이동)
  +) 표 중간에 데이터가 비어 있다면 비어 있는 셀 전으로 이동 (바로 옆 셀이 비어 있다면 해당 방향에서 처음으로 값이 입력된 셀로 이동)

16. Ctrl + Backscpace : 현재 활성화된 셀 확인

17. Ctrl + Home, Ctrl + End : 처음/마지막 셀로 이동

18. Ctrl + G (또는 F5) : 이동 대화상자 실행

19. Ctrl + Space : 열 전체 선택\

20. Ctrl + 9, Ctrl + 0 : 행/열 숨기기(Ctrl + 9를 사용하면 전체 행을 숨기고, Ctrl + 0을 사용하면 전체 열을 숨긴다.)

[Alt 조합] : 'Alt'를 누른 후 다른 키를 순서대로 눌러서 실행하므로 다소 느릴 수 있다. 
장점
  리본 메뉴에서 제공되는 거의 모든 기능을 단축키로 실행할 수 있다.
  Alt를 누르면 리본 메뉴에 기능별 단축키가 표시되어 별도로 외우지 않아도 된다.
1. Alt -> P -> R -> S : 인쇄 영역 설정
  +) Alt -> P -> R -> S 를 순서대로 눌러 인쇄 영역을 설정하고, Ctrl + P를 눌러 인쇄 미리 보기를 확인한다.

2. Alt -> W -> F -> F : 행/열 틀 고정 (기준이 될 셀이나 행/열 머리글을 선택하고 해당 단축키를 사용하여 틀 고정을 실행한다.)

3. Alt + Enter : 셀 안에서 줄 바꿈

4. Alt -> H -> B -> A : 선택된 범위 테두리 적용 (선택된 범위의 바깥쪽과 안쪽에 기본 테두리가 적용된다.)
  +) 선택한 범위의 바깥쪽에만 테두리를 적용하고 싶다면 Ctrl + Shift + 7을 누른다.

5. Alt + ; : 선택된 범위에서 보이는 데이터만 선택 (숨겨진 행이나 열이 포함된 범위에서 눈에 보이는 데이터만 선택하는 경우에 사용)
   
[Shift 조합]
1. Shift + F11 : 새로운 시트 삽입 (작업 중인 시트 왼쪽으로 새로운 시트를 빠르게 추가할 수 있다.)

2. Shift + F10 : 팝업 메뉴(마우스 우클릭 메뉴)표시

3. Shift + Space : 헹 전체 선택

[혼합]
1.  Ctrl + Shift + PageUp/PageDown : 여러 시트를 선택하는 경우 (시트를 다중 선택한 상태에서 선택되지 않은 시트를 선택하면 다중 선택이 해제된다.)

2.  Ctrl + Alt + +/- 를 통해 화면을 확대 축소할 수 있다.

3.  Ctrl + Shift + U : 수식 입력줄 확장 : 복잡한 수식을 작성할 때 수식 입력줄을 확장하거나 축소하여 전체 수식을 파악하는데 용이하게 해준다.

4.  Ctrl + Shift + L : 자동 필터 적용 (범위를 정렬하거나 범위엥서 원하는 값만 필터링하는 경우에 사용)

5.  Ctrl + Shift + \ : 선택한 범위의 특정 행이나 열을 기준으로 다른 값을 구분하는 경우

6. Ctrl + Shift + [ 또는 Ctrl + Shift + ] : 이전/이후 단계의 모든 셀을 한 번에 선택

7. Ctrl + Shift + 방향키 : 표의 끝까지 한 번에 선택

8. Alt + Shift + -> , Alt + Shift + <- : 범위 그룹화/그룹 해제

9. Ctrl + Shift + 9, Ctrl + Shift + 0 : 행/열 보이기 (Ctrl + Shift + 9 : 숨긴 행을 다시 표시하려고 할 때, Ctrl + Shift + 0 : 숨긴 열을 다시 표시하려고 할 때)

[혼합 - 특정 서식 빠르게 적용]
1. Ctrl + Shift + ` : 일반 서식
2. Ctrl + Shift + 1(!) : 숫자 서식
3. Ctrl + Shift + 2(@) : 시간 서식
4. Ctrl + Shift + 3(#) : 날짜 서식
5. Ctrl + Shift + 4($) : 통화 서식
6. Ctrl + Shift + 5(%) : 백분융 서식
7. Ctrl + Shift + 6(^) : 지수 서식

[F계열}
1. F4 : 이전 작업 반복 (이전 작업을 반복 수행하려고 하는 경우에 사용)

2. F2 : 활성화된 셀 즉시 편집 (이미 값이 입력된 셀을 편집하려고 하는 경우에 사용)
+) 수식을 편집하는 경우에도 많이 사용함 (데이터 유효성 검사나 조건부 서식의 수식을 수정하는 경우)
