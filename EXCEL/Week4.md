# 1️⃣ 학습 내용 정리

## 05-1. 엑셀 데이터 관리의 기본 규칙
> **데이터 관리를 할 때 주의해야 할 점에 대해 설명해주세요.**
#### 1. 줄 바꿈, 빈 셀은 사용하지 않는다. 
##### [줄 바꿈으로 발생하는 문제]
- 텍스트와 날짜가 한 셀에 줄 바꿈으로 입력되어 있어 기본적인 수식 계산 시 오류가 발생

##### [빈 셀로 발생하는 범위 선택 문제]
- 중간에 비어 있는 셀이 포함되어 단축키가 제 역할을 하지 못한다.  (이 경우 데이터가 많지 않다면 직접 드래그해서 범위를 선택)

##### [빈 셀 참조 시 0이 반환]
- 비어 있는 셀을 참조한 결과 값으로 0이 반환되는데 이로 인해 잘못된 정보를 전달할 우려가 있다. 

#### 2. 집계 데이터와 원본 데이터는 구분해서 관리한다.
##### [함께 관리하면 함수 사용이 어려워진다]
- 데이터 테이블내에 소계가 존지한다면 오히려 총 합계를 계산할 때 원본 데이터 값 혹은 집계 값을 따로 선택해야 하는 번거로움이 발생한다.

##### [함께 관리하면 피벗 테이블 사용이 어려워진다.]
- 원본 데이터와 집계 데이터가 혼재되어 있으면 피벗 테이블을 사용할 때 문제가 발생한다. 
- 총 합계 데이터에 집계 데이터가 포함되어 있어 이중으로 계산된다. 

##### [따로 관리하면 파일 크기를 최소화할 수 있다.]
- 다른 값을 참조하여 계산되는 값도 집계 데이터에 해당하며, 집계 데이터를 최소화할수록 원본 데이터의 크기를 최소화하여 PC에서 부담 없이 데이터를 관리할 수 있다. 
+) 집계 데이터를 반드시 포함해야 한다면 **수식으로 입력된 셀을 값 형태** 로 바꿔 저장하면 처리 속도를 크게 향상 시킬 수 있다. 

#### 3. 머리글은 반드시 한 줄로 입력한다.
##### [범위 선택의 문제]
- 셀 병합되어 있는 경우 특정 열의 합계를 구하기 위해서는 번거롭게 직접 입력하거나 범위를 드래그해서 인수를 지정해야 한다. 

##### [표, 피벗 테이블 활용의 문제]
- 데이터의 머리글을 두 줄로 관리할 때 가장 큰 문제이다. 
- 표를 만들 때 뿐만 아니라 머리글이 병합된 범위를 선택한 후 피번 테이블을 만들어도, '피번 테이블 필드 이름이 잘못되었습니다.'라는 오류 메시지가 표시되어 피벗 테이블 생성이 제한된다.

#### 4. 데이터 관리를 위한 핵심 규칙, 세로 방향 블록 쌓기
- **데이터 관리 = 세로 방향 블록 쌓기**
- 세로 방향 블록 쌓기란 **새로운 데이터는 아래 방향으로 추가** 하고, **새로운 항목은 오른쪽으로 추가** 하는 형태로 관리하는 것

##### [변경이 어려운 표 구조 문제] - 예 : 월별 매출 관리 데이터
- 오전과 오후 시간대를 나누어 입력하면 세로 방향 블록 쌓기 규칙을 지킨 데이터는 **시간대 항목만 추가** 하면 된다. 
- 세로 방향 블록 쌓기 규칙을 지키지 않은 경우에는 수정하기 위해 대대적인 작업이 필요한다. 

##### [피벗 테이블을 사용할 때 발생하는 제약]
- 일별로 뎅디터를 정렬하거나 필터링해야 하는데 입고 일 필드가 나뉘어져 있으면 데이터 분석을 제대로 진행할 수 없다. 
- 또한 시간이 지날수록 관리해야 하는 필드의 개수도 늘어나 관리의 어려움을 겪게 된다. 

##### [누적 데이터 취합의 어려움]
- 메뉴는 세로 방향으로 작성했지만, 구매처가 오른쪽 방향으로 추가된 경우
- 월별로 시트를 나누어 관리할 수밖에 없고, 필요에 따라 데이터를 취합하는 추가 작업을 해야 하는 번거로움이 발생
